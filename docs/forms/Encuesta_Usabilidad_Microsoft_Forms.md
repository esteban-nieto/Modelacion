# Encuesta de usabilidad: preguntas para Microsoft Forms

Títulos y tipos listos para copiar en Microsoft Forms (Nuevo formulario → Agregar nueva pregunta). Este archivo sale de `docs/encuesta_usabilidad.md`.

Sección 1 · Perfil

1. ¿Qué rol probó? · Elección única · Administrador / Operador / Consulta
2. ¿Qué tan cómodo se siente usando aplicaciones web? · Calificación 1 a 5 (1 = nada cómodo, 5 = muy cómodo)
3. ¿Usó la aplicación desde un computador o desde un celular? · Elección única · Computador / Celular

Sección 2 · Tareas (respuesta para cada tarea: completada sin ayuda / con ayuda / no pude)

4. Iniciar sesión · Cuadrícula de elección única (filas: la tarea; columnas: Sin ayuda / Con ayuda / No pude)
5. Buscar un paciente por su documento · misma cuadrícula
6. Registrar una cita nueva · misma cuadrícula
7. Ver la cola de atención · misma cuadrícula
8. Descargar un reporte en CSV · misma cuadrícula
9. Interpretar el tablero que compara lo real con lo simulado · misma cuadrícula

Sección 3 · Escala de usabilidad (1 = totalmente en desacuerdo, 5 = totalmente de acuerdo)

Use una cuadrícula de calificación de 1 a 5 con estas 10 afirmaciones (ítems impares y pares del SUS):
10. Creo que me gustaría usar este sistema con frecuencia.
11. Encontré el sistema innecesariamente complejo.
12. Pensé que el sistema era fácil de usar.
13. Creo que necesitaría ayuda de una persona con conocimientos técnicos para usarlo.
14. Encontré las diferentes funciones del sistema bien integradas.
15. Pensé que había demasiada inconsistencia en el sistema.
16. Imagino que la mayoría de las personas aprendería a usar este sistema rápidamente.
17. Encontré el sistema muy incómodo de usar.
18. Me sentí muy seguro usando el sistema.
19. Necesité aprender muchas cosas antes de poder manejar el sistema.

Sección 4 · Preguntas abiertas

20. ¿Qué fue lo más difícil o confuso? · Texto de párrafo
21. ¿Qué mejoraría primero? · Texto de párrafo
22. ¿Los mensajes de error le resultaron claros? · Elección única · Sí / A veces / No

Configuración recomendada: anónima (no pedir correo), una respuesta por persona, mensaje de inicio que explique que es anónima y toma unos 5 minutos.

Cálculo SUS: en los ítems impares reste 1 a la respuesta; en los pares reste la respuesta a 5; sume y multiplique por 2,5. Un promedio superior a 68 se considera aceptable.
